## 🎨 Customization

### Personal Information
Update the following in `index.html`:
- Contact information (email, phone, LinkedIn)
- About section content
- Portfolio projects and case studies
- Services and pricing
- Testimonials

### Styling
The CSS uses CSS custom properties (variables) for easy theming:
```css
:root {
    --primary-color: #3b82f6;    /* Main brand color */
    --secondary-color: #6366f1;  /* Secondary color */
    --accent-color: #f59e0b;     /* Accent color */
    /* ... more variables */
}
```

### Analytics
To enable Google Analytics:
1. Get your tracking ID from Google Analytics
2. Uncomment the analytics code in `index.html`
3. Replace `GA_TRACKING_ID` with your actual tracking ID

## 🚀 Deployment

### Option 1: GitHub Pages
1. Create a GitHub repository
2. Upload all files
3. Enable GitHub Pages in repository settings
4. Your site will be available at `username.github.io/repository-name`

### Option 2: Netlify
1. Drag and drop the folder to [Netlify](https://netlify.com)
2. Your site will be live with a custom URL
3. Add a custom domain in Netlify settings

### Option 3: Vercel
1. Install Vercel CLI: `npm i -g vercel`
2. Run `vercel` in the project directory
3. Follow the prompts to deploy
